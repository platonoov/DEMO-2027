# DEMO-2027 — Менеджер учебных стендов Proxmox VE

Автоматизированное развёртывание и управление виртуальными стендами для подготовки к демонстрационному экзамену по направлению **«Сетевое и системное администрирование»** на базе Proxmox VE.

Проект позволяет создавать виртуальные машины, разворачивать сетевую инфраструктуру учебных стендов и управлять их жизненным циклом через удобное консольное меню.

## Возможности

* **Автоматическое создание стендов** по конфигурации из `conf.txt`.
* **Поддержка нескольких модулей** с разными наборами виртуальных машин.
* **Управление виртуальными машинами** через API и инструменты Proxmox VE.
* **Настройка виртуальной сети**: создание изолированных Linux bridges и подключение сетевых интерфейсов ВМ.
* **Выбор сетевого моста и хранилища** перед развёртыванием.
* **Управление стендами**: просмотр списка и удаление созданных ресурсов.
* **Учёт созданных ресурсов** с помощью манифестов для отслеживания состояния развёртывания.
* **Загрузка конфигурации напрямую из GitHub** без необходимости вручную хранить `conf.txt` на сервере.

## Поддерживаемые системы

В конфигурации могут использоваться следующие виртуальные системы:

* ALT Linux JeOS
* ALT Linux Server
* ALT Linux Workstation
* EcoRouterOS
* Ideco NGFW

Состав стенда, параметры виртуальных машин и сетевые подключения определяются конфигурационным файлом.

## Требования

* Proxmox VE с правами администратора.
* Bash и Python 3.
* `curl` для загрузки конфигурации.
* Настроенное хранилище Proxmox с необходимыми образами дисков.
* Сетевые мосты и свободные VMID для создаваемых виртуальных машин.
* Доступ к GitHub для загрузки конфигурации и скрипта.

## Быстрый запуск

Запуск основного скрипта непосредственно с GitHub:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/platonoov/DEMO-2027/main/e.sh)
```

После запуска откроется меню управления:

1. Создание стендов.
2. Управление стендами.
3. Выход.

При создании стенда необходимо выбрать модуль, указать количество стендов, сетевой мост и хранилище.

## Конфигурация

Основные параметры задаются в `conf.txt`, который загружается из репозитория.

Конфигурация определяет:

* шаблоны виртуальных машин;
* объём оперативной памяти и количество процессорных ядер;
* диски и источники образов;
* сетевые интерфейсы и виртуальные сети;
* состав модулей и названия стендов;
* параметры пользователей.

Изменение конфигурации позволяет адаптировать развёртывание под конкретную учебную инфраструктуру без изменения основной логики скрипта.

## Безопасность и восстановление

* Перед созданием стенда проверяйте выбранный сетевой мост и хранилище.
* Не используйте управляющий мост Proxmox для учебных сетей без необходимости.
* Не удаляйте вручную ресурсы, которые могут принадлежать другим стендам.
* При ошибке развёртывания проверяйте сохранённый манифест и список фактически созданных ВМ перед повторным запуском.
* Для конфигурации с VLAN учитывайте необходимость корректной настройки виртуальных мостов и сетевых интерфейсов.
